# შეცდომების კატალოგი (რა გვემართა ლაბში)

| შეცდომა | მიზეზი | როგორ გავასწორეთ |
|---|---|---|
| `No such file or directory` სწორ გზაზე | ბრძანება **არასწორ კომპიუტერზე** გავუშვით (კლიენტზე სერვერის ფაილი) | `prompt`-ის შემოწმება; `hostname` |
| `Could not resolve hostname <alias>` | alias მხოლოდ კლიენტის `~/.ssh/config`-შია; ბრძანება სერვერზე გავუშვით | `exit` და ბრძანება კლიენტზე |
| `Host` ბლოკი 3-4-ჯერ ჩაიწერა | `cat >> ... <<EOF` ბრძანება რამდენჯერაც გავუშვით, იმდენჯერ დაემატა | `cp config.bak config` და ერთხელ დამატება |
| `~/.ssh/config`-იდან ძველი ჩანაწერი დაიკარგა | ხელით რედაქტირებისას წაიშალა | აღდგენა `config.bak`-იდან. **ყოველთვის ჯერ ასლი** |
| `sudo nano` პირადი ფაილისთვის | ფაილი ჩვენია, `sudo` არ სჭირდება | `nano` უბრალოდ |
| `syntax error near unexpected token '('` | ბრძანებას `(07)` მიაწერეს (ჩემი ეტიკეტი) | ბრძანებაში კომენტარი არ უნდა ჩაიწეროს |
| `mk: command not found` | არარსებული ბრძანება (`md` Windows-ისაა) | `mkdir` |
| `grep -c ERROR` = 6, ნამდვილი = 5 | INFO ხაზის message-ში `ERROR` წერია | level ველის შემოწმება `$2=="ERROR"` |
| `checklist`: world-writable = 3 | `find -perm -o+w` ბმულებსაც იჭერს | `find . -not -type l -perm -o+w` |
| `ls -l current` ვერ იპოვა | არასწორი დირექტორია | სრული გზა ან სწორი `cd` |
| `rmdir: Directory not empty` | `rmdir` მხოლოდ ცარიელს შლის | ჯერ `cp -r` ასლი, მერე `rm -r` |
