# ზეპირად: ბრძანებების ცნობარი

## 2.1 ნავიგაცია და ფაილები

| ბრძანება | რას აკეთებს | მაგალითი |
|---|---|---|
| 🔴 `pwd` | სად ვარ | `pwd` |
| 🔴 `cd <გზა>` | გადავდივარ დირექტორიაში (`..` ზემოთ, `~` home, `-` წინა) | `cd ~/linux-week1` |
| 🔴 `ls`, `ls -l`, `ls -a`, `ls -la` | სია, დეტალები, დამალულებიც | `ls -la` |
| 🔴 `ls -R` | რეკურსიულად (ქვესაქაღალდეებიც) | `ls -R ~/linux-week1` |
| 🔴 `mkdir`, `mkdir -p` | დირექტორია, `-p` მშობელებიც და არსებულზე არ ჩივის | `mkdir -p a/b/c` |
| 🔴 `touch f` | ცარიელი ფაილი (ან დროს ანახლებს) | `touch a.txt` |
| 🔴 `cp f g`, `cp -r d1 d2` | ასლი (საქაღალდეზე `-r`) | `cp -r env backup` |
| 🔴 `mv a b` | გადატანა ან გადარქმევა | `mv a.txt docs/` |
| 🔴 `rm f`, `rm -r d` | წაშლა (**სანაგვე ყუთი არ არსებობს**) | `rm old.txt` |
| 🔴 `rmdir d` | მხოლოდ **ცარიელი** დირექტორიის წაშლა | `rmdir empty` |
| 🔴 `cat f`, `head -N`, `tail -N`, `less f` | წაკითხვა: მთლიანი, დასაწყისი, ბოლო, გვერდებად | `tail -5 app.log` |
| 🔴 `tail -f f` | ფაილის **ცოცხალი** ყურება (გამოსვლა `Ctrl+C`) | `tail -f live.log` |
| 🔴 `wc -l f` | ხაზების რაოდენობა | `wc -l app.log` |

> 💡 `less`-ში: `/სიტყვა` ეძებს, `q` გამოდის.

## 2.2 ძებნა

| ბრძანება | რას ეძებს | მაგალითი |
|---|---|---|
| 🔴 `find . -type f` | ჩვეულებრივ ფაილებს (დამალულებსაც) | `find . -type f` |
| 🔴 `find . -type d` | დირექტორიებს | `find . -type d` |
| 🔴 `find . -name "*.txt"` | **სახელით** | `find . -name "*.log"` |
| 🔴 `find . -name ".*" -type f` | დამალულ ფაილებს | |
| 🔴 `grep -r "ტექსტი" გზა` | **შიგთავსში**, რეკურსიულად | `grep -r "DOC-017" documents` |
| 🔴 `grep -rl "ტექსტი" გზა` | მხოლოდ ფაილების სახელებს | |
| `grep -c "x" f` | შესატყვისი ხაზების რაოდენობა | |

> 💡 **სახელით ძებნა** (`find`) და **შიგთავსით ძებნა** (`grep`) სხვადასხვა რამეა: სახელი შეიძლება არაფერს ამბობდეს შიგთავსზე.

## 2.3 ტექსტის დამუშავება

| ბრძანება | რას აკეთებს |
|---|---|
| 🔴 `awk '$2=="ERROR"' f` | ხაზებს ტოვებს, სადაც **მეორე ველი** არის ERROR (`$1` პირველი, `$2` მეორე ...) |
| 🔴 `awk '{print $4}' f` | ბეჭდავს მხოლოდ მეოთხე ველს |
| 🔴 `sort` | ალაგებს |
| 🔴 `uniq` | ერთმანეთის გვერდით განმეორებულს ერთად ტოვებს (ამიტომ ჯერ `sort`); `uniq -d` მხოლოდ დუბლიკატებს |
| 🔴 `sed -i 's/ძველი/ახალი/' f` | ფაილში ტექსტს **ადგილზე** ცვლის |
| `sed -n 1p f` | ბეჭდავს მხოლოდ პირველ ხაზს |
| `cut -d' ' -f2` | სივრცით გაყოფილი მეორე ნაწილი |

## 2.4 ოპერატორები (რომლებიც მუდმივად გვჭირდება)

| ოპერატორი | მნიშვნელობა | შენიშვნა |
|---|---|---|
| 🔴 `>` | გამოტანა ფაილში, **ზედმიწერს** | ძველი შიგთავსი იკარგება |
| 🔴 `>>` | გამოტანა ფაილში, **ბოლოში ამატებს** | ორჯერ გაშვებაზე ორჯერ დაემატება |
| 🔴 <code>&#124;</code> (pipe) | ერთის გამოტანა მეორეს შესატანად | <code>awk ... &#124; sort &#124; uniq</code> |
| 🔴 `*` | ნებისმიერი სიმბოლოები სახელში | `*.txt` |
| 🔴 `{a,b,c}` | ჩამონათვალი | `mkdir -p env/{dev,prod}/app` |
| `$(...)` | ბრძანების შედეგი ტექსტად | `echo "$(whoami)"` |
| `&&` | მეორე გაეშვება, თუ პირველი წარმატებულია | `cd x && ls` |
| `<<'EOF' ... EOF` | მრავალხაზიანი ტექსტი | `cat > f <<'EOF'` |

## 2.5 უფლებები

```text
-rwxr-xr--      <- ls -l-ის პირველი სვეტი
│└┬┘└┬┘└┬┘
│ │  │  └── სხვები (others)
│ │  └───── ჯგუფი (group)
│ └──────── მფლობელი (owner)
└────────── ტიპი: - ფაილი, d დირექტორია, l ბმული
```

| ასო | ციფრი | ფაილზე | დირექტორიაზე |
|---|---|---|---|
| 🔴 `r` | 4 | წაკითხვა | **სახელების ჩამოთვლა** |
| 🔴 `w` | 2 | ჩაწერა | შიგ ფაილის შექმნა/წაშლა |
| 🔴 `x` | 1 | გაშვება | **შესვლა** და შიგნით წვდომა |

| რიცხვი | ასოებით | გამოყენება |
|---|---|---|
| 🔴 `644` | `rw-r--r--` | საჯარო ფაილი |
| 🔴 `640` | `rw-r-----` | ჯგუფისთვის ხილული |
| 🔴 `600` | `rw-------` | პირადი ფაილი, პირადი გასაღები |
| 🔴 `700` | `rwx------` | პირადი დირექტორია |
| 🔴 `755` | `rwxr-xr-x` | ჩვეულებრივი დირექტორია |
| ⛔ `777` | `rwxrwxrwx` | **არ გამოიყენო**: ყველას აძლევს ყველაფერს |

გამოთვლა: თითო სამეულში `r=4`, `w=2`, `x=1`, ვაჯამებთ. მაგ. `rw-` = 4+2 = 6.

## 2.6 ბმულები და არქივი

| ბრძანება | რას აკეთებს |
|---|---|
| 🔴 `ln -s სამიზნე ბმული` | სიმბოლური ბმული (მალსახმობი) |
| 🔴 `ln -sfn სამიზნე ბმული` | არსებულს ცვლის (`-f` იძულებით, `-n` ბმულს არ შეიჭრება) |
| `readlink ბმული` | სად მიუთითებს |
| 🔴 `tar -czf a.tar.gz საქ1 საქ2` | არქივის შექმნა + gzip |
| 🔴 `tar -tzf a.tar.gz` | შემადგენლობა **ამოღების გარეშე** (`-tvzf` დეტალებით) |
| 🔴 `tar -xzf a.tar.gz -C დირ` | ამოღება მითითებულ დირექტორიაში |
| `tar -xzf a.tar.gz გზა/ფაილი` | მხოლოდ **ერთი** ფაილის ამოღება |
| 🔴 `gzip -k f`, `gunzip f.gz` | შეკუმშვა (`-k` ორიგინალს ტოვებს), გაშლა |
| 🔴 `sha256sum f > f.sha`, `sha256sum -c f.sha` | ფაილის "თითის ანაბეჭდი" და შემოწმება (`OK`) |
| `cmp a b` | ორი ფაილი ზუსტად ერთნაირია თუ არა |

## 2.7 SSH და გადატანა

| ბრძანება | რას აკეთებს |
|---|---|
| 🔴 `ssh user@host` ან `ssh alias` | სერვერზე შესვლა |
| 🔴 `ssh-keygen -t ed25519 -f ~/.ssh/<სახელი> -C "კომენტარი"` | გასაღებების წყვილი |
| 🔴 `ssh-copy-id -i ~/.ssh/<სახელი>.pub user@host` | **საჯარო** გასაღები სერვერზე |
| 🔴 `ssh-keygen -lf <.pub ფაილი>` | გასაღების fingerprint |
| `ssh-keygen -lF <host>` | `known_hosts`-ში ჩანაწერის fingerprint |
| 🔴 `scp წყარო დანიშნულება` | ფაილის გადატანა SSH-ით (`alias:გზა` სერვერის მხარეა) |
