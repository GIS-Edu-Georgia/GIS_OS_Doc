# დაცვა (Task 42): მოკლე ნიმუშები

ლექტორი აირჩევს რამდენიმე თასქს, მოგთხოვს **შედეგის ჩვენებას** და **მცირე ნაწილის გამეორებას**. პასუხები ააგე **შენს ფაილებზე და მოქმედებებზე**.

| თემა | მოკლე პასუხი |
|---|---|
| ბრძანება და მისი პარამეტრები | სახელი + რას აკეთებს + თითოეული პარამეტრი (`-r` რეკურსიულად, `-a` დამალულიც, `-p` მშობლებიც, `-n` არ გადააწეროს) |
| კლიენტი, სერვერი, SSH სესია | კლიენტი იწყებს, სერვერი ასრულებს; SSH სესია დაშიფრული კავშირია, რომელშიც ბრძანებები გადის |
| public / private გასაღები | საჯარო სერვერზე დევს (`authorized_keys`), პირადი კლიენტზე რჩება და **არავის ეძლევა** |
| აბსოლუტური / შეფარდებითი გზა | აბსოლუტური `/`-იდან, ყველგან მუშაობს; შეფარდებითი მიმდინარე დირექტორიიდან |
| კოპირება / გადატანა / წაშლა | `cp` ასლი (ორიგინალი რჩება), `mv` გადააქვს, `rm` საბოლოოდ შლის (ურნა არ არსებობს) |
| ძებნა სახელით / შიგთავსით | `find` სახელს, `grep -r` შიგთავსს |
| ლოგის გაფილტვრა და გადამოწმება | `awk '$2=="ERROR"'`; ჯამის გადამოწმება: INFO+WARN+ERROR = სულ ხაზები |
| ფაილისა და დირექტორიის უფლებები | ფაილზე `x` = გაშვება; დირექტორიაზე `x` = შესვლა, `r` = სახელების ნახვა |
| სიმბოლური ბმული | გზამკვლევი სამიზნეზე; დაზიანებული ბმული = სამიზნე აღარ არსებობს; გასწორება `ln -sfn` |
| backup და აღდგენა | `tar -czf` შექმნა, `tar -tzf` შემოწმება, `sha256sum -c` დამტკიცება |
| dev / staging / prod | შემუშავება / რეპეტიცია / რეალური; გამიჯნულია უსაფრთხოებისთვის |
| რა გაგიჭირდა | მაგ.: კლიენტი/სერვერის აღრევა, `>>`-ის ორჯერ გაშვება, ცრუ განგაში ბმულებზე |

**რჩევა დაცვისთვის:** თუ ლექტორი ითხოვს გამეორებას, ჯერ **`pwd` და `ls`**, მერე ბრძანება. ხმამაღლა თქვი, რას აკეთებ და რატომ.
