# 💻 Basic and recommended computer resources for QGIS

This page lists the minimum and recommended computer resources students should consider for using QGIS — from basic data processing to spatial analysis.

---

## 📊 Requirements table

| Component       | Minimum requirement                     | Recommended                                    |
|------------------|------------------------------------------|-----------------------------------------------|
| 🧠 Memory (RAM) | 4 GB                                | 8 GB or more (16 GB is better)                 |
| ⚙️ Processor (CPU)         | Dual-core, 2.0 GHz                   | Quad-core or more, ≥ 2.5 GHz                  |
| 💾 Storage   | 10 GB of free space             | SSD ≥ 256 GB (QGIS + project data)  |
| 🖥️ Graphics (GPU)          | Integrated graphics                | A dedicated GPU is better, but not required |
| 📺 Screen               | ≥ 1366x768                          | ≥ 1920x1080 (Full HD)                         |
| 💽 Operating system     | Windows 8.1 / macOS 10.13 / Ubuntu 18.04 | Windows 10/11, macOS 12+, Ubuntu 22.04+   |

---

## 🔎 Additional recommendations

- ✅ An **SSD** speeds up data access and QGIS considerably.
- ✅ More RAM = better multitasking (e.g. processing several layers/maps in parallel).
- ✅ **Monitor quality** matters for seeing map details clearly.
- ✅ An external mouse (not a touchpad) is better for precise drawing and editing.

---

## 🧪 What does QGIS do that needs resources?

- displaying and styling spatial data
- filtering data and working with attribute tables
- georeferencing and digitizing data
- spatial analysis (buffer, clip, intersection, etc.)
- working with raster data

---

## 🛍️ If you are buying a new computer:

🎯 Goal: hardware that is enough for studying and later for professional GIS work too.

**Recommended configuration**:

- 16 GB RAM
- Intel i5/i7 or AMD Ryzen 5/7
- SSD ≥ 512 GB
- 15.6" Full HD screen
- Windows 11 / Ubuntu 22.04
