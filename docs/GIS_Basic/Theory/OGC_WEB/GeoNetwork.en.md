# 📚 What is GeoNetwork? — simply, for students

## 🧾 In short: what is GeoNetwork?

**GeoNetwork** is an open-source system for managing spatial metadata.  
It helps organizations and users **search, share and manage metadata**.

🎯 Its main goal is:
> better organization and discovery of geographic data over the internet.

---

## 🔍 What does metadata mean?

**Metadata** means a description of data.  
For example, information about a map layer:
- who created it?
- when was it created?
- what does it represent?
- what format is it in?
- how can it be used?

📌 GeoNetwork is focused on storing and finding exactly this information in a structured way.

---

## 🌐 How does GeoNetwork work?

| Capability | Description |
|--------------|--------|
| 🔎 Search | Find map layers, data, documents |
| 📋 Description | See a layer's author, license, tags, location |
| 📁 Catalogues | Organize data by theme |
| 📤 Export / import | With the ISO, INSPIRE and Dublin Core standards |
| 🧩 Integration | Works with GeoServer, GeoNode, CKAN and other systems |

---

## 🧪 For students: what can GeoNetwork be used for?

- 📁 finding specific layers or data for a project
- 📝 describing their own uploaded layers with correct metadata
- 🧠 learning international standards (ISO 19115)
- 🌍 using it in SDI (Spatial Data Infrastructure) projects

---

## 👨‍💻 The technical side

GeoNetwork is built on:
- Java and the Spring Framework
- XML data processing
- a PostgreSQL database
- a connection to GeoServer (e.g. for layer metadata)

---

## 📚 How is it different from GeoNode?

| Characteristic | GeoNode | GeoNetwork |
|---------------|---------|------------|
| Serving layers | ✅ yes | ❌ no |
| Metadata | ✅ yes, but simpler | ✅ detailed, standardized |
| Map visualization | ✅ yes | 🔸 viewing only |
| Integration with SDI | medium | ✅ high |
| ISO standards | partly | ✅ full support |

➡️ **GeoNode** is more of a GIS platform, while **GeoNetwork** is a metadata catalogue system.
