# 🌍 What is GeoNode, and how can students use it

## 🧾 Simply: what is GeoNode?

**GeoNode** is an open-source platform for managing and sharing geographic data.

🎯 Goal:  
👉 to make it easy even for non-geographers to create maps and to upload and share data over the internet.

📦 GeoNode combines:
- 🗂️ a data store (vector/rasters)
- 🗺️ tools for creating web maps
- 👥 user management and access control
- 🔗 integration with GeoServer, PostGIS and other systems

---

## 🚀 What does GeoNode do in practice?

| Function | Description |
|--------|--------|
| 📤 Uploading data | Students can upload SHP, GeoTIFF, CSV |
| 🗺️ Creating maps | Easily add layers and create web maps |
| 👥 Sharing | Share maps or data with a link |
| 🔐 Access management | Users can decide who can or cannot see the data |
| 📊 Metadata | The system stores information about layers (author, project, description) |

---

## 🧪 For students: how to use GeoNode

1. **Go to the platform** (e.g. `https://your-geonode-instance.org`)
2. **Register or sign in**
3. **Upload a file** – use the Upload menu, choose SHP/GeoTIFF/CSV
4. **Add a description and metadata**
5. **Create a map** – use the Map Composer
6. **Share the map or data** with a link or by embedding it (iframe)

---

## 🔧 GeoNode runs on these technologies

- **GeoServer** – serving layers (WMS/WFS)
- **PostGIS** – storing data in a spatial database
- **Django** – the website framework (in Python)
- **React** – the visual map interface
- **MapStore** – the map management interface

---

## 📚 How will it help students?

✅ easily process, share and present spatial data  
✅ work in teams on projects  
✅ learn data management, access and metadata  
✅ gain experience on a real GIS platform
