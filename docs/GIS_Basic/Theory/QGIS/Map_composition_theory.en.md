# Map composition

Map composition is the correct arrangement of all the elements of a map so that the information is communicated effectively and clearly. A well-designed map improves perception and helps the user interpret the data correctly.

---

## 🧩 Main composition elements

| Element           | Description |
|--------------------|--------|
| **Title**     | A short, precise description that shows what the map is about. |
| **Legend**     | Explains the symbols and colours. |
| **Scale**     | Shows how distances on the map correspond to real space. |
| **North Arrow** | Helps with orientation. |
| **Graticule/Grid** | A coordinate grid or geographic graticule on the map. |
| **Data source** | States where the data comes from. |
| **Author and date** | Gives the map's author and the date it was made. |

---

## 🎯 The purpose of map composition

- to present data visually in a clear, logical way
- to make the map easier to read
- to give the user context, with the elements needed for interpretation
- to give a professional and aesthetic impression

---

## 🛠️ Creating a map composition in QGIS

1. From the menu choose **Project → New Print Layout**.
2. Give it a name and confirm.
3. Use the tools to add elements to the composition:
   - `Add Map` – to insert the map
   - `Add Legend`, `Add Scale Bar`, `Add North Arrow` – for the corresponding elements
   - `Add Label` – to add text
4. Adjust the size, colours, font and layout.
5. Print it or save it as PDF/PNG.

---

## ✅ Rules for a good map composition

- use contrasting colours for readability
- do not overload the map with unnecessary elements
- labels should be clear and clean
- the legend should include only the symbols that are on the map

---

## 📌 An example map might include:

- a title: "Population of Tbilisi districts 2024"
- a scale: "1:50,000"
- a legend: data classified by colour
- a north arrow in the upper right corner
- a source note: "Data: Geostat, 2024"

---

Map composition combines cartography, design and spatial analysis — it is the final product we share with other people. That is why planning and executing it is just as important as processing the data.
