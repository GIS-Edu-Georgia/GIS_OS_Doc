# QGIS

## We use:

- **QGIS (Quantum GIS)** | version [QGIS 3.40  LTR](https://qgis.org/download/)

- QGIS is an open-source platform for spatial analysis and map making that gives users a wide range of capabilities for collecting, managing, analysing and visualizing data. It is widely used in urban planning, environmental protection, transport analysis and public policy. QGIS has a strong modular architecture and a wide variety of extensions (plugins), and it can work both on the desktop and on web platforms. Using it supports decision-making, data-driven planning and a spatial view in real time.

# 🧭 The history of QGIS

**QGIS (Quantum GIS)** is a free and open-source geographic information system (GIS) that lets users process, explore and visualize geographic data.

## 🕰️ The beginning — from idea to program

- **2002** – The idea of QGIS came from the Canadian programmer **Gary Sherman**, who was looking for an open-source GIS tool to use on Linux.
- His goal was to create a **simple, fast, cross-platform GIS program** supporting the main spatial formats.

## 🛠️ The first versions

- **July 2002** – the project was started on SourceForge.
- **October 2002** – the first public version (v0.1) was released; it supported only raster layers and GRASS data.
- The program was written **with C++ and the Qt libraries**, which made it cross-platform (Windows, Linux, macOS).

## 🚀 Development and growth

- **2004–2008** – support for vector layers, GRASS integration, a plugin system and a WMS client were added.
- **2009** – the **QGIS Project Steering Committee (PSC)** was created to coordinate the project's development.
- **2013** – the project changed its name from **Quantum GIS → QGIS** to make it easier to identify.
- **From 2016** – regular releases begin with the LTR (Long Term Release) model.

## 🌍 QGIS today

- ✅ translated into 50+ languages  
- ✅ has a **versatile plugin system**  
- ✅ integrates with **GRASS GIS, SAGA, PostGIS, GeoServer, Python, R**  
- ✅ used by environmental agencies, universities, municipalities and humanitarian organizations.

## 🎓 Why QGIS?

- 💸 **It is free, with no license restrictions**  
- 🧩 easily extended with plugins  
- 🛠️ runs on all major operating systems  
- 🌐 an active community and continuous development
