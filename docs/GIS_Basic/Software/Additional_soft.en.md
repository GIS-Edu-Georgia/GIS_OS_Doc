# 🗺️ GIS basic course

## ➕ Additional software

This page lists additional software recommended for the **GIS basic course**. These tools are not GIS platforms themselves, but they matter for managing and processing data and for running the course effectively.

---

### 🗜️ 1. 7-Zip

**7-Zip** is a free and open-source file archiver known for its high compression ratio.

#### Use in the GIS course:

* 📦 compressing and transferring GIS data (Shapefile, GeoPackage, Raster)
* 📚 archiving course materials and sharing them easily
* 🗂️ organizing and storing large GIS projects

#### Supported formats:

* 7z, ZIP, TAR, GZIP, RAR (read) and others

#### Advantages:

* high compression
* fast
* simple interface
* cross-platform (Windows, Linux)

---

### 💻 2. Visual Studio Code (VS Code)

**Visual Studio Code** is a free, lightweight and powerful code editor, widely used for programming, including Python.

Website:

* [https://code.visualstudio.com/](https://code.visualstudio.com/)

Use in the GIS course:

* 🐍 writing and running Python scripts (with GDAL, GeoPandas, Rasterio and other libraries)
* 📜 automating GIS workflows
* 🧩 using extensions (Python, Jupyter, Git)

---

### 🛰️ 3. RoboGEO

**RoboGEO** is a specialized program for georeferencing photos using GPS metadata.

Website:

* [https://www.robogeo.com/](https://www.robogeo.com/)

Use in the GIS course:

* 📸 attaching photos to locations (geotagging / georeferencing)
* 🗺️ preparing fieldwork data for a GIS environment
* 🌍 photo-based spatial analysis

Note:

* the program is commercial (a trial version is available)

---

### 🐍 4. Python

**Python** is a popular, easy-to-learn programming language and one of the main tools for GIS automation and analysis.

Website:

* [https://www.python.org/](https://www.python.org/)

Use in the GIS course:

* 🧮 processing and analysing spatial data
* ⚙️ automating GIS processes
* 📊 visualizing data

Main GIS libraries:

* GeoPandas
* GDAL / OGR
* Rasterio
* Shapely
* PyProj

---

### ☕ 5. Java

**Java** is a widely used programming language and platform that some GIS tools and libraries need.

Website:

* [https://www.java.com/](https://www.java.com/)

Use in the GIS course:

* ⚙️ running GIS programs and plugins
* 🧩 using Java-based spatial tools

Note:

* often needed to install other programs (e.g. GeoServer)

---

### 🗄️ 6. DBeaver

**DBeaver** is a free and open-source universal database manager.

Website:

* [https://dbeaver.io/](https://dbeaver.io/)

Use in the GIS course:

* 🗃️ working with spatial databases (SQLite, PostGIS and others)
* 📑 viewing and editing attribute data
* 🔍 running SQL queries

---

### 🗃️ 7. SQLite

**SQLite** is a lightweight, file-based database widely used in GIS.

Website:

* [https://www.sqlite.org/](https://www.sqlite.org/)

Use in the GIS course:

* 🗺️ storing spatial data (SpatiaLite)
* 📊 managing attribute data
* 🔗 integration with QGIS and other GIS programs

---

### 🐙 8. GitHub Desktop

**GitHub Desktop** is a graphical program for Git version control.

Website:

* [https://desktop.github.com/](https://desktop.github.com/)

Use in the GIS course:

* 🔄 version control for code and projects
* 👥 group work on GIS and Python projects
* 📁 managing course assignments
