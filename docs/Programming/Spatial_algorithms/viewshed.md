# 👁️ ხილვადობა (Viewshed)

**ხედვის არე (viewshed)** არის რუკის ყველა ის ადგილი, რომელიც მოცემული წერტილიდან ჩანს. ამას იყენებენ სმარტფონის ანძების განლაგებაში, ხანძარსაწინააღმდეგო კოშკურების დაგეგმვაში, ქარის ტურბინების ვიზუალური გავლენის შეფასებაში და ტურისტული ხედების ანალიზში. ყველაფერი ერთ კითხვაზე დგას: **ხედავს თუ არა წერტილი `A` წერტილ `B`-ს, თუ რელიეფი ხელს უშლის?**

---

## 💡 იდეა: ხედვის ხაზი (line of sight)

`A`-დან `B`-მდე გავავლოთ სწორი ხაზი და ვნახოთ, **რელიეფი რომელიმე წერტილში ამ ხაზს ზემოთ ხომ არ ადის**. ამისთვის რელიეფის ყოველ უჯრაზე ვითვლით **დახრილობას** დამკვირვებლის თვალიდან:

```text
slope(უჯრა) = (უჯრის სიმაღლე − თვალის სიმაღლე) / მანძილი
```

სამიზნე ჩანს მაშინ და მხოლოდ მაშინ, თუ **მისი დახრილობა ყველა შუალედური უჯრის დახრილობაზე არანაკლებია**. ასე ვინახავთ მხოლოდ ერთ რიცხვს, ზრდადი მაქსიმუმის სახით (`max_slope`), და ყოველ უჯრაზე ერთი შედარება გვაქვს.

უჯრებს ხაზზე **ბრეზენჰემის ალგორითმი** (Bresenham) ირჩევს: ის რასტრზე სწორი ხაზის უახლოეს უჯრებს აბრუნებს მხოლოდ მთელი რიცხვებით.

## 🐍 რეალიზაცია სუფთა Python-ით

```python title="view.py" linenums="1"
import math


def bresenham(r0, c0, r1, c1):
    """უჯრები (r0,c0)-დან (r1,c1)-მდე სწორ ხაზზე, ბოლოების ჩათვლით."""
    cells = []
    dr, dc = abs(r1 - r0), abs(c1 - c0)
    sr = 1 if r1 > r0 else -1
    sc = 1 if c1 > c0 else -1
    err = dc - dr
    r, c = r0, c0
    while True:
        cells.append((r, c))
        if (r, c) == (r1, c1):
            return cells
        e2 = 2 * err
        if e2 > -dr:
            err -= dr
            c += sc
        if e2 < dc:
            err += dc
            r += sr


def line_of_sight(dem, obs, target, h_obs=1.7, h_target=0.0, cell=30.0):
    """ხედავს თუ არა დამკვირვებელი obs=(r,c) სამიზნეს target=(r,c).
    cell = უჯრის ზომა მეტრებში, სიმაღლეები მეტრებში."""
    (r0, c0), (r1, c1) = obs, target
    z0 = dem[r0][c0] + h_obs
    max_slope = -math.inf
    path = bresenham(r0, c0, r1, c1)[1:]
    for r, c in path:
        d = math.hypot(r - r0, c - c0) * cell
        if (r, c) == target:
            return (dem[r][c] + h_target - z0) / d >= max_slope
        max_slope = max(max_slope, (dem[r][c] - z0) / d)   # ხაზი ამ უჯრის ზედაპირს ეხება
    return True                                            # obs == target


def viewshed(dem, obs, h_obs=1.7, h_target=0.0, cell=30.0):
    """ლოგიკური მატრიცა: True = უჯრა ჩანს."""
    rows, cols = len(dem), len(dem[0])
    return [[line_of_sight(dem, obs, (r, c), h_obs, h_target, cell) for c in range(cols)] for r in range(rows)]
```

import math
from view import *


def terr(r, c):
    return 120 + 60 * math.sin(c / 9) * math.cos(r / 7) + 35 * math.sin((r + c) / 13) + 25 * math.cos(c / 4.5) * math.sin(r / 5)


dem = [[terr(r, c) for c in range(60)] for r in range(40)]     # 40 x 60, უჯრა 30 მ
vs = viewshed(dem, (20, 30), h_obs=10)

JavaScript-ის ვერსია, რომელიც დემოშია, იგივე რიცხვებს იძლევა (1000, 1091, 1385 უჯრა 1.7, 10 და 50 მ-ზე).

!!! info "სირთულე"
    ყოველი უჯრისთვის ხაზი `O(L)` ბიჯია (`L` რასტრის სიგრძეა), ამიტომ მთელი ხედვის არე `O(N·L)`. ეს მარტივი **„ყველა ხაზი ცალ-ცალკე"** ვერსიაა. **R2/R3 და sweep-line** ალგორითმები (მაგ. GRASS-ში) ხედვის არეს გაცილებით სწრაფად იღებენ, ზოგს ინფორმაციას ხაზებს შორის ინახავენ.

## 📚 იგივე ბიბლიოთეკით

=== "GDAL"

    ```bash
    gdal_viewshed -ox 44.80 -oy 41.72 -oz 10 -tz 0 -md 20000 dem.tif viewshed.tif
    ```

    `-oz` დამკვირვებლის სიმაღლეა, `-tz` სამიზნის, `-md` მაქსიმალური მანძილი. ნაგულისხმევად GDAL ითვალისწინებს დედამიწის სიმრუდესაც (`-cc` კოეფიციენტი).

=== "QGIS (PyQGIS)"

    ```python
    import processing

    processing.run('gdal:viewshed', {
        'INPUT': 'dem.tif', 'BAND': 1,
        'OBSERVER': '44.80,41.72 [EPSG:4326]',
        'OBSERVER_HEIGHT': 10, 'TARGET_HEIGHT': 0,
        'MAX_DISTANCE': 20000, 'OUTPUT': 'viewshed.tif'})
    ```

!!! warning "რა არის შემოწმებული"
    ბიბლიოთეკების ფრაგმენტები **არ გამიშვია** ამ გარემოში (GDAL და QGIS არ არის დაყენებული). პარამეტრების სახელები დოკუმენტაციასთან შეამოწმეთ, განსაკუთრებით GDAL-ის ვერსიაზე, რადგან `gdal_viewshed` ახალი ბრძანებაა.

!!! question "დავალება 3: დედამიწის სიმრუდე"
    დაამატეთ `line_of_sight`-ს ვერსია, რომელიც მანძილზე `d` სიმაღლეს ამცირებს `(1 − k)·d² / (2R)`-ით (`R = 6 371 km`, რეფრაქციის `k = 0.13`). შეადარეთ ხილული უჯრები უჯრის ზომებზე 30, 300 და 1000 მ (იგივე რელიეფის სიმაღლეებით).

    ??? success "ამოხსნა"
        ```python
        R_EARTH = 6371000.0
        K_REFR = 0.13


        def los_curved(dem, obs, target, h_obs, h_target=0.0, cell=30.0):
            (r0, c0), (r1, c1) = obs, target
            z0 = dem[r0][c0] + h_obs
            drop = lambda d: (1 - K_REFR) * d * d / (2 * R_EARTH)
            max_slope = -math.inf
            for r, c in bresenham(r0, c0, r1, c1)[1:]:
                d = math.hypot(r - r0, c - c0) * cell
                if (r, c) == target:
                    return (dem[r][c] + h_target - drop(d) - z0) / d >= max_slope
                max_slope = max(max_slope, (dem[r][c] - drop(d) - z0) / d)
            return True


        obs = (20, 30)
        for cell in (30, 300, 1000):
            flat = sum(sum(line_of_sight(dem, obs, (r, c), 10, 0, cell) for c in range(60)) for r in range(40))
            curv = sum(sum(los_curved(dem, obs, (r, c), 10, 0, cell) for c in range(60)) for r in range(40))
            print(f'უჯრა {cell:4} მ: სიმრუდის გარეშე {flat}, სიმრუდით {curv}')

        def greedy(dem, k, h=10, step=5):
            cands = [(r, c) for r in range(0, 40, step) for c in range(0, 60, step)]
            vs = {p: {(r, c) for r in range(40) for c in range(60) if line_of_sight(dem, p, (r, c), h)} for p in cands}
            chosen, covered = [], set()
            for _ in range(k):
                best = max(cands, key=lambda p: len(vs[p] - covered))
                chosen.append(best)
                covered |= vs[best]
                print(f'  + {best}: ჯამური დაფარვა {100 * len(covered) / total:.1f}%')
            return chosen


        greedy(dem, 4)
