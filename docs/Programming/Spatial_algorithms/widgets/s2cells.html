დააჭირეთ ადგილს რუკაზე (ან აირჩიეთ ქალაქი). რუკა მიახლოვდება უჯრის „ბაბუაზე" (დონე − 2). ნაჩვენებია მისი 16 შთამომავალი ამ დონეზე, ლურჯი ხაზი Hilbert-ის მრუდია. შერჩეული უჯრა შევსებულია. ბიტებში: მეწამული = წახნაგი, ლურჯი = პოზიციის ციფრები (დონეზე ორ-ორი ბიტი), წითელი = ბოლო „1".
