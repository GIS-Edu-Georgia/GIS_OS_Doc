# 🌐 გლობალური ბადეები: S2 და H3

[ბადეების გვერდზე](grids_hex.md) ვნახეთ, როგორ ხდება 2D უჯრის ერთ რიცხვად გადაქცევა. ახლა იგივე იდეა **მთელ დედამიწაზე**: **დისკრეტული გლობალური ბადე** (DGGS) ყოველ წერტილს ერთ **უჯრის ID**-ს აძლევს და სივრცითი კითხვები (ახლო წერტილები, რეგიონში მოხვედრა, აგრეგაცია) **მთელ რიცხვებზე ოპერაციებად** იქცევა. ამ ადგილას სრულიად ჩვეულებრივი ბაზა ან დახარისხებული სია გვყოფნის და სპეციალური სივრცითი ინდექსი აღარ გვჭირდება.

ორი ყველაზე ცნობილი სისტემაა:

| | **Geohash** | **S2** (Google) | **H3** (Uber) |
|---|---|---|---|
| ფორმა | მართკუთხედი განედ-გრძედზე | „კვადრატი" კუბის წახნაგზე | ექვსკუთხედი (+12 ხუთკუთხედი) იკოსაედრზე |
| უჯრების დაშლა | 32 შვილი | 4 შვილი | 7 შვილი |
| ინდექსი | Z-order | Hilbert | ჰიერარქიული, ბიტებად შეფუთული |
| მკაფიო მშობელ-შვილობა | კი (პრეფიქსი) | **კი** (ID-ს დიაპაზონი) | **დაახლოებით** (ზუსტად ერთმანეთში არ ეტევა) |
| პოლუსებთან დამახინჯება | **დიდი** | მცირე (≈ 2× ფართობი) | მცირე (≈ 2× ფართობი) |

ეს გვერდი S2-ს **ნულიდან** ააგებს Python-ში და შეამოწმებს ბიბლიოთეკასთან, შემდეგ აჩვენებს, როგორ გამოიყურება **სივრცითი ძებნა დახარისხებულ სიაში**, და ბოლოს H3-ს შეხედავს ექსპერიმენტებით.

## 🎮 სცადეთ თქვენც: S2 უჯრის ID

აირჩიეთ ადგილი რუკაზე და გადაადგილეთ **დონის** სლაიდერი. ბიტებში ჩანს, როგორ „იზრდება" ID ყოველი დონით: წახნაგის 3 ბიტი, შემდეგ **ორ-ორი ბიტი ყოველი დონისთვის**, ბოლოს ერთი „1" და ნულები.

## ⚙️ როგორ აგებს S2 უჯრის ID-ს

წერტილი `(lat, lng)` რამდენიმე ბიჯით გადაიქცევა 64-ბიტიან რიცხვად:

1. **სფერო → კუბი.** `(lat, lng)` გადავიყვანოთ ერთეულოვან ვექტორად `(x, y, z)`. კუბის ის **წახნაგი**, რომლის ღერძსაც ვექტორი ყველაზე ახლოა, არის `face` (0…5).
2. **წახნაგზე კოორდინატები** `(u, v) ∈ [−1, 1]` ცენტრალური (გნომონური) პროექციით: ვექტორს ვყოფთ მისი ყველაზე დიდი კომპონენტით.
3. **კვადრატული გარდაქმნა** `u → s`, `v → t ∈ [0, 1]`. უშუალოდ `(u,v)` ბადე კუთხეებში უჯრებს **ბევრად პატარას** ხდის, ვიდრე ცენტრში. კვადრატული ფორმულა ამას აკორექტირებს და უჯრების ფართობებს თითქმის გაუთანაბრებს.
4. **დისკრეტიზაცია** 30-ე დონეზე: `i = ⌊s · 2³⁰⌋`, `j = ⌊t · 2³⁰⌋`.
5. **Hilbert-ის პოზიცია.** `i` და `j`-ს ბიტებს ზევიდან ქვევით ვკითხულობთ. ყოველ დონეზე წყვილი `(iₖ, jₖ)` მიუთითებს, რომელი ოთხი ქვეკვადრატია, ხოლო მრუდის **ორიენტაცია** (გაცვლილია თუ არა `i` და `j`, შებრუნებულია თუ არა) გადაწყვეტს ამ ორბიტიან „ციფრს" და ცვლის ორიენტაციას შემდეგი დონისთვის. 60 ბიტი გამოდის.
6. **შეფუთვა:** `ID = face(3 ბიტი) | pos(60 ბიტი) | 1`. მარცხენა `2·(30 − დონე)` ბიტი ნულებად რჩება და ბოლო „1" **დონეს აღნიშნავს**: ბოლო ერთი „1"-ის ადგილი გვეუბნება, რომელ დონეზე ვართ.

**შედეგები** (ყველა მარტივი ბიტური ოპერაცია):

- **დონე** = ბოლო „1"-ის ადგილით.
- **მშობელი** = ბოლო ბიტების ჩამოჭრა და ახალი „1"-ის დაყენება.
- **შვილები** = 4 ახალი „1"-ის ადგილი (ორი ბიტით ქვემოთ).
- **შთამომავლების დიაპაზონი** = `[ID − lsb + 1, ID + lsb − 1]`: უწყვეტი დიაპაზონი.

## 🐍 S2 ნულიდან Python-ში

```python title="s2cell.py" linenums="1"
import math

MAX_LEVEL = 30
SWAP, INVERT = 1, 2
POS_TO_IJ = ((0, 1, 3, 2), (0, 2, 3, 1), (3, 2, 0, 1), (3, 1, 0, 2))   # პოზიცია -> (i<<1 | j), ორიენტაციის მიხედვით
POS_TO_ORIENT = (SWAP, 0, 0, INVERT | SWAP)


def latlng_to_xyz(lat, lng):
    phi, theta = math.radians(lat), math.radians(lng)
    return (math.cos(theta) * math.cos(phi), math.sin(theta) * math.cos(phi), math.sin(phi))


def xyz_to_face_uv(p):
    face = max(range(3), key=lambda k: abs(p[k]))
    if p[face] < 0:
        face += 3
    x, y, z = p
    u, v = {0: (y / x, z / x), 1: (-x / y, z / y), 2: (-x / z, -y / z),
            3: (z / x, y / x), 4: (z / y, -x / y), 5: (-y / z, -x / z)}[face]
    return face, u, v


def face_uv_to_xyz(face, u, v):
    return {0: (1, u, v), 1: (-u, 1, v), 2: (-u, -v, 1),
            3: (-1, -v, -u), 4: (v, -1, -u), 5: (v, u, -1)}[face]


def uv_to_st(u):                     # კვადრატული პროექცია: უჯრების ფართობები თანაბარს უახლოვდება
    return 0.5 * math.sqrt(1 + 3 * u) if u >= 0 else 1 - 0.5 * math.sqrt(1 - 3 * u)


def st_to_uv(s):
    return (4 * s * s - 1) / 3 if s >= 0.5 else (1 - 4 * (1 - s) ** 2) / 3


def face_ij_to_id(face, i, j):
    """უჯრის ID 30-ე დონეზე: 3 ბიტი წახნაგი + 60 ბიტი Hilbert-ის პოზიცია + 1 ბოლო ბიტი."""
    orient = face & SWAP
    pos = 0
    for k in range(MAX_LEVEL - 1, -1, -1):
        ij = (((i >> k) & 1) << 1) | ((j >> k) & 1)
        digit = POS_TO_IJ[orient].index(ij)
        pos = (pos << 2) | digit
        orient ^= POS_TO_ORIENT[digit]
    return (face << 61) | (pos << 1) | 1


def latlng_to_cell(lat, lng, level=MAX_LEVEL):
    face, u, v = xyz_to_face_uv(latlng_to_xyz(lat, lng))
    n = 1 << MAX_LEVEL
    i = max(0, min(n - 1, int(uv_to_st(u) * n)))
    j = max(0, min(n - 1, int(uv_to_st(v) * n)))
    return parent(face_ij_to_id(face, i, j), level)


def lsb(cell):
    return cell & -cell


def level(cell):
    return MAX_LEVEL - ((lsb(cell).bit_length() - 1) >> 1)


def parent(cell, lvl):
    new = 1 << (2 * (MAX_LEVEL - lvl))
    return (cell & -new) | new


def children(cell):
    step = lsb(cell) >> 2
    return [cell - lsb(cell) + step * (2 * k + 1) for k in range(4)]


def range_min(cell):
    return cell - (lsb(cell) - 1)


def range_max(cell):
    return cell + (lsb(cell) - 1)


def cell_to_face_ij(cell):
    """(წახნაგი, i, j, ზომა): უჯრის მინიმალური კუთხე 30-ე დონის უჯრებში და გვერდის სიგრძე."""
    face = cell >> 61
    lvl = level(cell)
    orient = face & SWAP
    i = j = 0
    for k in range(lvl):
        digit = (cell >> (60 - 2 * k - 1)) & 3
        ij = POS_TO_IJ[orient][digit]
        i = (i << 1) | (ij >> 1)
        j = (j << 1) | (ij & 1)
        orient ^= POS_TO_ORIENT[digit]
    size = 1 << (MAX_LEVEL - lvl)
    return face, i * size, j * size, size


def cell_to_latlng(cell):
    """უჯრის ცენტრი."""
    face, i, j, size = cell_to_face_ij(cell)
    n = 1 << MAX_LEVEL
    return face_ij_point_to_latlng(face, (i + size / 2) / n, (j + size / 2) / n)


def face_ij_point_to_latlng(face, s, t):
    x, y, z = face_uv_to_xyz(face, st_to_uv(s), st_to_uv(t))
    return math.degrees(math.atan2(z, math.hypot(x, y))), math.degrees(math.atan2(y, x))


def cell_to_token(cell):
    return f'{cell:016x}'.rstrip('0') or '0'
```

from s2cell import *

c = latlng_to_cell(41.72, 44.80, 17)                         # თბილისი, 17-ე დონე
print('ID:      ', c)
print('ტოკენი:  ', cell_to_token(c), ', დონე', level(c))
print('ბიტები:  ', format(c, '064b'))
print('ცენტრი:  ', tuple(round(v, 5) for v in cell_to_latlng(c)))
p = parent(c, 10)
print('მშობელი (10):', cell_to_token(p), '| შვილები:', [cell_to_token(x) for x in children(p)])
leaf = latlng_to_cell(41.72, 44.80, 30)
print('ფოთოლი უჯრის დიაპაზონშია:', range_min(c) <= leaf <= range_max(c))

## 🔍 რეგიონის ძებნა დახარისხებულ სიაში

აი რატომ გვჭირდება ეს ყველაფერი. წერტილების ID-ებს **ვახარისხებთ** (ბაზაში ეს ჩვეულებრივი B-tree ინდექსია). კითხვა „რა მოხვდა 10 კმ-იან წრეში?" ასე იხსნება:

1. **დავფაროთ** წრე უჯრებით: დავიწყოთ 6 წახნაგით და ყოველი უჯრა ან გამოვტოვოთ (წრის გარეთაა), ან მთლიანად ავიღოთ (შიგნითაა), ან გავყოთ 4 შვილად. მესამე შემთხვევა მაქსიმალურ დონეზე ჩერდება.
2. ყოველი უჯრა არის **ერთი უწყვეტი ID დიაპაზონი**. მეზობელ დიაპაზონებს ვაერთებთ.
3. ყოველი დიაპაზონისთვის `bisect`-ით ვპოულობთ წერტილებს დახარისხებულ სიაში.
4. კანდიდატებზე ზუსტი მანძილით ვფილტრავთ, რადგან ფარვა ზედმეტსაც შეიცავს.

უჯრის „ქუდს" (შემომსაზღვრელ წრეს) **კუთხეებიდან ცენტრამდე მაქსიმალური კუთხით** ვითვლით. უჯრა ამოზნექილია (გვერდები დიდი წრის რკალებია), ამიტომ ცენტრიდან ყველაზე შორეული წერტილი მისი წვეროა.

```python title="cover.py" linenums="1"
import bisect
import math
import random
from s2cell import *


def angle(a, b):
    """ცენტრალური კუთხე ორ ერთეულოვან ვექტორს შორის (რადიანებში)."""
    d = a[0] * b[0] + a[1] * b[1] + a[2] * b[2]
    return math.acos(max(-1.0, min(1.0, d)))


def unit(p):
    n = math.sqrt(sum(c * c for c in p))
    return tuple(c / n for c in p)


def cell_cap(cell):
    """უჯრის შემომსაზღვრელი „ქუდი": (ცენტრი ერთეულოვან ვექტორად, რადიუსი რადიანებში)."""
    face, i, j, size = cell_to_face_ij(cell)
    n = 1 << MAX_LEVEL
    pt = lambda a, b: unit(face_uv_to_xyz(face, st_to_uv(a / n), st_to_uv(b / n)))
    center = pt(i + size / 2, j + size / 2)
    corners = [pt(i, j), pt(i + size, j), pt(i, j + size), pt(i + size, j + size)]
    return center, max(angle(center, c) for c in corners)


def cover_circle(lat, lng, radius_m, max_level):
    """უჯრები, რომელთა გაერთიანება მთლიანად ფარავს წრეს (ზედმეტიც შეიძლება შეიცავდეს)."""
    c0 = latlng_to_xyz(lat, lng)
    r0 = radius_m / 6371008.8
    out, stack = [], [f << 61 | 1 << 60 for f in range(6)]      # 6 წახნაგი (0 დონე)
    while stack:
        cell = stack.pop()
        center, rad = cell_cap(cell)
        d = angle(c0, center)
        if d > r0 + rad:
            continue                                            # მთლიანად გარეთაა
        if d + rad <= r0 or level(cell) == max_level:
            out.append(cell)                                    # მთლიანად შიგნითაა, ან უკვე უმცირესია
        else:
            stack.extend(children(cell))
    return sorted(out)


def merge_ranges(cells):
    """მეზობელი უჯრების ID დიაპაზონები გავაერთიანოთ."""
    ranges = []
    for c in sorted(cells):
        lo, hi = range_min(c), range_max(c)
        if ranges and lo <= ranges[-1][1] + 2:
            ranges[-1][1] = max(ranges[-1][1], hi)
        else:
            ranges.append([lo, hi])
    return ranges
```
