# 🐍 PyQGIS learning stages

## 1️⃣ Basics  
- Getting to know the QGIS environment (Layers, CRS, Project Structure)  
- The Python Console in QGIS  
- Overview of the PyQGIS API  
- Running your first script  
 
---

## 2️⃣ QGIS object basics  
- QgsProject – managing the project  
- QgsVectorLayer / QgsRasterLayer – loading layers  
- QgsFeature – attributes and geometry  
- QgsGeometry – points, lines, polygons  

---

## 3️⃣ Reading and editing data  
- Getting features from a layer (`getFeatures()`)  
- Reading and changing attributes  
- Editing geometry (adding a new point, drawing a line)  
- Exporting data (Shapefile, GeoJSON, GPKG)  

---

## 4️⃣ Spatial analysis  
- Buffers  
- Overlay (Intersection, Union, Difference)  
- Calculating distance and area  
- CRS transformations (Coordinate Transformations)  

---

## 5️⃣ Classes and modularity in PyQGIS  
- Using classes in PyQGIS scripts  
- Manager classes (LayerManager, GeometryManager)  
- Inheritance for different types of objects  
- Splitting into modules (Utilities.py, Analysis.py)  

---

## 6️⃣ GUI and interface development  
- Integrating PyQt with PyQGIS  
- ToolButton, Dialog, Input widgets  
- QgsMapCanvas – showing a map in the interface  
- A simple plugin skeleton (with Plugin Builder or by hand)  

---

## 7️⃣ Automation and scripting  
- Model → Script conversion  
- Batch processing with PyQGIS  
- Automatic data processing (e.g. CSV → Shapefile → Buffer)  
- Logging and error handling  

---

## 8️⃣ Advanced topics  
- PyQGIS + PostgreSQL/PostGIS connection  
- PyQGIS + Processing Toolbox  
- Network Analysis, Routing  
- Raster Analysis (DEM, slope, hillshade)  
- PyQGIS + Web (QGIS Server, using the PyQGIS API in a backend)  

---

## 9️⃣ Capstone Project  
- A small project where students write their own PyQGIS script or plugin  
- Loading data → analysis → visualizing the result  
- Documenting the code and sharing it on GitHub  

---

# 🔹 Summary  
The best way to learn PyQGIS:  
1. Basics (QGIS + Python Console)  
2. Object basics (Layers, Features, Geometry)  
3. Data management  
4. Spatial analysis  
5. Classes and modularity  
6. GUI and plugins  
7. Automation  
8. Advanced topics  
9. Final project
