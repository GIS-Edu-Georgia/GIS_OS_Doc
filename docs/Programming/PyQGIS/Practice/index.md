## 💡 ამოხსნები

ყოველი ამოცანის ქვეშ არის დაკეცილი ბლოკი **„ამოხსნა"**. ჯერ სცადეთ დამოუკიდებლად და ბლოკი გახსენით მხოლოდ შემდეგ.
ამოხსნებში ბილიკები და სვეტების სახელები ილუსტრაციისთვისაა; მოარგეთ თქვენს მონაცემებს.

??? tip "ზოგადი დამხმარე კოდი (გამოიყენება ყველა დავალებაში)"
    ```python
    from qgis.core import *
    import processing

    base = r'C:/Users/Public/Documents/practice'   # თქვენი სამუშაო საქაღალდე

    def save_shp(layer, path):
        """ინახავს შრეს Shapefile-ად (UTF-8)."""
        opts = QgsVectorFileWriter.SaveVectorOptions()
        opts.driverName = 'ESRI Shapefile'
        opts.fileEncoding = 'UTF-8'
        res = QgsVectorFileWriter.writeAsVectorFormatV3(
            layer, path, QgsProject.instance().transformContext(), opts)
        return res[0] == QgsVectorFileWriter.NoError
    ```
