# Labs

RHCSA is a **practical** exam — you are given a live system and complete tasks against a timer.
Reading notes is not enough for that. This section collects scenarios you have to do by hand.

!!! tip "How to work on a lab"
    1. Take a **clean** virtual machine (a snapshot is a must).
    2. Start a timer.
    3. Try the solution **without help** first — `man` and `--help` are allowed, the internet is not (the same as in the exam).
    4. Only after that, look at the answer.
