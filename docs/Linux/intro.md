# Linux გეოგრაფებისთვის

ეს არ არის კიდევ ერთი ლინუქსის სახელმძღვანელო. ინტერნეტში ასეთი ათასია და ბევრი მათგანი
შესანიშნავია. აქ სხვა რამეა: **ლინუქსი გეოგრაფის ამოცანების ჭრილში.**

განსხვავება მარტივი მაგალითით ჩანს. ჩვეულებრივი სახელმძღვანელო `find`-ს ასე გასწავლის:

```bash
find /path -name "*.txt"
```

აქ კი ასე:

```bash
# 1 200 ორთოფოტოდან იპოვე ის, რომლებიც 2024 წელს გადაიღეს
# და ერთ საქაღალდეში გადაიტანე — ხელით 1 200 ფაილს არ გადაათრევ
find /data/ortho -name "*_2024*.tif" -exec mv {} /data/ortho_2024/ \;
```

ერთი და იგივე ბრძანებაა. მეორე გემახსოვრება, რადგან იმ ტკივილს ხსნის, რომელიც ნამდვილად გქონია.

---

## რატომ სჭირდება გეოგრაფს ლინუქსი

!!! question "„QGIS Windows-ზეც მუშაობს — მერე რა?\""

    მართალია. QGIS-ისთვის ლინუქსი არ გჭირდება. მაგრამ:

    - **სერვერები ლინუქსია.** GeoServer, PostGIS, MapProxy, GeoNode — თუ ოდესმე გინდა,
      რომ შენი რუკა ვებზე გავიდეს და არა მხოლოდ შენს ლეპტოპზე იყოს, სერვერთან გექნება საქმე.
    - **GDAL ბრძანების ველზეა აშენებული.** QGIS-ის ღილაკები GDAL-ის ბრძანებების გარსია.
      როცა 300 რასტრის დამუშავება გჭირდება, ღილაკს 300-ჯერ არ დააჭერ.
    - **დისტანციური ზონდირება და ML ინსტრუმენტები** — თითქმის ყველა ჯერ ლინუქსზე გამოდის.
    - **უფასოა და გამჭვირვალე.** ეს ისეთივე ღირებულებაა, როგორც QGIS-ის ღია კოდი.

## ვისთვისაა

გეოგრაფისთვის, GIS სპეციალისტისთვის, სტუდენტისთვის, რომელსაც ლინუქსზე ხელი არ უხლია.
წინარე ცოდნა არ გჭირდება — ვიწყებთ იქიდან, თუ რა არის ტერმინალი.

სასურველია, თუ უკვე იცნობ QGIS-ს — მაშინ GIS მაგალითები უფრო გამოგადგება.
თუ არა, [GIS საბაზისო](../GIS_Basic/Software/QGIS.md) კარგი დასაწყისია.

## როგორ ისწავლო

!!! danger "ერთადერთი წესი"
    **კითხვით ლინუქსს ვერ ისწავლი.** ყველა ბრძანება ხელით აკრიფე. არა კოპირებით — **აკრიფე.**
    შეცდომები, რომლებსაც აკრეფისას დაუშვებ, სწორედ ის ადგილებია, სადაც ცოდნა გიჩერდება.

**გჭირდება სავარჯიშო სისტემა.** არ გამოიყენო სამუშაო კომპიუტერი. ვარიანტები
[00 — მომზადების](00_Setup/index.md) თავშია: ვირტუალური მანქანა (რეკომენდებული),
dual-boot, ან WSL.

თავები თანმიმდევრობით დაწერილია — 01-დან 12-მდე. თითოეული ეყრდნობა წინას.
